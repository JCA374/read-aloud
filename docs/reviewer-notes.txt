Neural Voices reads web pages and PDFs aloud. Speech is made inside the browser with Piper voices
running as WebAssembly; no server, no data collection.

- 'wasm-unsafe-eval' in the CSP runs WebAssembly (ONNX Runtime Web, espeak-ng via piper-wasm, pdf.js
  image decoders).
- Minified code is only third-party libraries, unchanged from npm: onnxruntime-web 1.30.0,
  @diffusionstudio/piper-wasm 1.0.0, pdfjs-dist 6.4.299 (engine/vendor/, pdf/). tools/check-vendor.sh in
  the source package compares all 204 files with npm byte for byte. Details: THIRD-PARTY-NOTICES.
- No remote code: voice models are ONNX data files (weights) run by the bundled ONNX Runtime. pdf.js runs
  with scripting off and isEvalSupported: false.
- Lint warnings: UNSUPPORTED_API is chrome.offscreen in background.js (Chromium only, not run in Firefox).
  UNSAFE_VAR_ASSIGNMENT is inside the minified libraries.
- Network: voice models from huggingface.co/rhasspy/piper-voices (pinned revision, size-checked) the
  first time a voice is used; samples from rhasspy.github.io when the user presses "Try"; a PDF the user
  asks to read, from its own site (optional host permission, asked per site); an add-on's public store
  text from addons.mozilla.org/api/v5 when the user asks to read a store page (reader.html), since content
  scripts can't run there.
- Permissions: content script on all pages (reads the text, shows the player); storage; contextMenus;
  activeTab (popup checks whether the tab is a PDF); optional host permissions, per site, for PDFs.
- Language detection: browser.i18n.detectLanguage (local).
- Data: declared "none". Page text never leaves the browser.
- Privacy policy: https://github.com/JCA374/read-aloud/blob/main/PRIVACY.md
- Source: https://github.com/JCA374/read-aloud (GPL-3.0). ./build.sh zips extension/ with the licence
  files; no transpiling or bundling.

How to test:
1. Open an article (e.g. Wikipedia), click the toolbar button, "Read page". The first time the English
   voice downloads (about 63 MB), then reading starts with sentence and word highlighted. Alt+Shift+R
   pauses, Alt+Shift+X stops.
2. Select text: a speaker button appears; click it to hear the selection.
3. Open a PDF (e.g. https://arxiv.org/pdf/1706.03762), toolbar button, "Read this PDF". It opens in the
   add-on's viewer (pdf.html) and is read; the first time per site it may ask for permission.
4. Settings (gear on the player): voices per language, Try samples, downloads, pronunciations.
No account needed.
